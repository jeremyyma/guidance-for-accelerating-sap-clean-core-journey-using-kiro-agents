   - kiro-cli --version should return 2.14.x or higher
   - Verify: which kiro-cli

================================================================================
INTERPRETING RESULTS
================================================================================

Quality Scoring Guide:

  ATC Accuracy (9-10):
    - All violations correctly identified
    - No false positives
    - Comprehensive coverage across package

  Documentation Clarity (9-10):
    - All methods documented completely
    - Clear business context
    - Code examples provided
    - Easy to understand

  Dead Code Detection (8-10):
    - Finds actual unused code
    - Minimal false positives
    - Safety assessment provided
    - Easy to remediate

  Performance:
    - Execution time < 5 minutes = Excellent
    - 5-15 minutes = Good
    - > 15 minutes = Consider model choice

Cost vs Quality Analysis:
  - If cost difference < 20%, choose higher quality
  - If cost difference > 50%, consider trade-off
  - For production, prioritize quality
  - For development, can use cost-effective model

SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

1. "Model not found" error
   → Verify API key is set: echo $ANTHROPIC_API_KEY
   → If empty, set it: export ANTHROPIC_API_KEY="your-key"

2. "SAP connection failed"
   → Check SAP environment: cat mcp/sap.env
   → Start MCP: ./mcp/mcp-launcher.sh &
   → Test connection: curl https://<SAP_HOST>/sap/bc/adt/discovery

3. Results not saving
   → Check permissions: chmod 755 reports/model-comparison/
   → Verify kiro_result/ directory exists
   → Check disk space: df -h

For more help, see QUICKSTART.md troubleshooting section.
